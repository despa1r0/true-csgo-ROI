# trueROI — каталог и сравнение CS2-предметов

Веб-приложение сравнивает цены CS2-предметов и рассчитывает реальную прибыль после комиссий. Текущий этап — локальный каталог с живыми данными CSFloat и CSGO Market.

## Что уже работает

1. PostgreSQL в Docker с постоянным volume.
2. Автоматический импорт актуальных скинов из ByMykel/CSGO-API.
3. Поиск по частичному названию с превью.
4. Фильтры по оружию, редкости и коллекции.
5. Отдельные карточки wear-качеств с минимальной ценой CSFloat.
6. Модальный список конкретных лотов выбранного качества.
7. Синхронизация общего индекса цен CSFloat с PostgreSQL.
8. Ленивое получение 10 листингов с float, pattern seed/index и стикерами.
9. Изображения стикеров и их справочная цена CSFloat.
10. Текущие buy orders и цена быстрой продажи.
11. Доступная история продаж и beta-оценка ликвидности по spread, depth и velocity.
12. Фильтры листингов по float, Normal / StatTrak™ / Souvenir, цене, наличию наклеек и charm.
13. Подробная аналитика конкретного лота внутри модального окна.
14. Сортировка CSFloat `best_deal` без локальной подмены алгоритма.
15. Существующий чистый расчёт прибыли и ROI.
16. Публичный индекс цен, конкретные лоты, стакан и история CSGO Market.
17. Общий PostgreSQL-кэш для обеих площадок.
18. Сравнение цен и обеих направлений сделки с учётом комиссий.
19. Защищённый лимит приватного API CSGO Market: не более 4 запросов/с.

## Модель данных

`skins` хранит базовый скин, например `AK-47 | Redline`. `skin_variants` хранит реальные рыночные варианты, например `StatTrak™ AK-47 | Redline (Field-Tested)`. Связь выполняется по `skin_id` источника.

Рыночное имя, float-диапазон, paint index, редкость, изображение и исходный JSON сохраняются в БД. `skin_collections` связывает скины с коллекциями. `marketplace_listings` хранит индекс цен, `marketplace_syncs` — время общей синхронизации, `marketplace_variant_details` — кэш подробных листингов и метрик.

## Формула прибыли

```text
effective_buy = buy_price + buy_fees
effective_payout = sell_price - sell_fees
profit = effective_payout - effective_buy
roi = profit / effective_buy * 100
```

Деньги передаются и хранятся в центах, а не в `float`. Profit Engine не выполняет HTTP-запросы и работает только с нормализованными ценами и комиссиями.
