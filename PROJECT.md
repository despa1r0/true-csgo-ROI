# Skin Market Tracker

## Что это

Веб-приложение для сравнения цен на CS2-скины и расчёта **реальной** возможной прибыли.

Оно отвечает не только на вопрос «где предмет дешевле», но и на вопрос:

> Если купить предмет на одной площадке и продать на другой, останется ли прибыль после комиссий?

## Первый рабочий сценарий

Пользователь выбирает предмет, например `AK-47 | Redline (Field-Tested)`.

Приложение показывает цены на доступных площадках и рассчитывает результат сделки:

```text
Купить на CSFloat:   $18.40
Продать на CS.MONEY: $19.70
Комиссии:            $0.97
Прибыль:             +$0.33
ROI:                 +1.78%
```

На самом первом этапе данные будут тестовыми (mock data). Это позволит сделать и проверить расчёт до подключения реальных API.

## MVP — первая версия

В первой версии нужны только:

1. Один заранее заданный предмет и несколько тестовых цен.
2. Таблица цен по площадкам.
3. Выбор: где купить и где продать.
4. Расчёт прибыли и ROI с комиссиями.
5. Простой веб-интерфейс.

В MVP пока не входят:

* реальные API площадок;
* поиск по всем предметам;
* ликвидность и история цен;
* портфель пользователя;
* автоматический поиск арбитража, уведомления и авторизация.

## Как считаем прибыль

```text
effective_buy = buy_price + buy_fees
effective_payout = sell_price - sell_fees
profit = effective_payout - effective_buy
roi = profit / effective_buy * 100
```

Комиссии должны быть видны пользователю отдельно. Расчёт не должен обращаться к API: он получает уже готовые цены и параметры комиссий.

## Что будет после MVP

Когда первый сценарий стабильно работает, добавляем по порядку:

1. Реальный адаптер одной торговой площадки.
2. Поиск предметов и больше площадок.
3. Ликвидность и свежесть данных.
4. Ручной портфель.
5. Историю, алерты и автоматический scanner.

## Принцип интеграций

Каждая площадка подключается через отдельный адаптер. Остальной код работает с общими моделями, а не с ответами конкретного API.

```text
API площадки → adapter → общая модель цены → расчёт прибыли → интерфейс
```
