# Технологический стек

## Backend

* Python 3.12+
* FastAPI — HTTP API для фронтенда
* Pydantic — проверка входных и выходных данных
* Pytest — тесты расчёта прибыли

На старте база данных не нужна: цены будут лежать в mock-данных. Когда появятся реальные источники и портфель, добавим PostgreSQL и SQLAlchemy.

## Frontend

* React
* TypeScript
* Vite

Первый экран: карточка предмета, таблица цен и блок с результатом расчёта.

## Минимальная структура

```text
backend/
  app/
    main.py            # FastAPI-приложение
    profit.py          # чистый расчёт прибыли
    mock_data.py       # временные тестовые цены
  tests/

frontend/
  src/
    App.tsx
```

## Первый API-контракт

```text
GET /api/market-overview
```

Временно возвращает один предмет, цены площадок и результат расчёта. Фронтенд строится поверх этого контракта; позднее mock-данные заменяются адаптерами реальных API без смены интерфейса.

## Правила

* Деньги передаём и храним в центах, а не в `float`.
* Profit Engine не делает HTTP-запросов.
* Внешние API добавляем только через отдельные adapter-модули.
* Сначала тестируем формулу прибыли, затем подключаем реальные данные.
