## Тесты со старым импортом: переносить, не удалять

В текущем репозитории не найдено тестовых файлов, которые можно уверенно удалить
как полностью устаревшие. `pytest --collect-only` собирает **299 тестов из 26 файлов**;

Обнаружение тестов само по себе не доказывает полноту покрытия.

  stickers/charm и API capabilities сохранить.

`scripts/qa/check-frontend.py` используется для браузерной проверки; нужен новый
сценарий перекрытия подсказок в калькуляторе, а не удаление скрипта.

## Оставить

В актуальном приложении не обнаружено целых неиспользуемых frontend/backend-модулей
при проверке импортов и известных входных точек. В частности, `Card` нужен
`RouteErrorPage`, графики подключены через lazy imports, `tokens.css` — через CSS import.
`check_marketplace_keys.py` и `start.ps1` — документированные ручные инструменты.
`docker-compose.csmoney-test.yml` — действующий отдельный стенд CS.MONEY.

`STACK.md`, `ROADMAP.md`, `PROJECT.md`, `README.md` имеют разные роли, удалять их
как «неиспользуемые» оснований нет. Два локальных `.venv` — в workspace и репозитории —
требуют выбора используемого окружения; текущая проверка запускалась из repo `.venv`.
Пользовательские заметки `rough fees on marketplaces.txt`, skills и `skills-lock.json`
не относятся к мусору приложения и не включены в рекомендации на удаление.
