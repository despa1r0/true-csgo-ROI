# Дебаг-режим: только ветка debug/site-diagnostics

Запускать из checkout этой ветки:

```bash
cd frontend-react
npm ci
npm run dev -- --host 127.0.0.1
```

В навигации появится `Debug`, страница `/debug`. Сначала откройте каталог / лот /
калькулятор, затем вернитесь в Debug: данные этой сессии остаются в кэше браузера.
При закрытом модальном окне ссылка Debug доступна в общей навигации.

- Журнал последних 100 API-запросов: путь без query string, HTTP-код, длительность,
  очищенный текст ошибки; запросы и ошибки прямых действий тоже фиксируются.
- Запросы TanStack Query: статус, запрос в процессе или простаивает, время обновления
  кэша браузера, отдельные `fetched_at` и ошибки компонентов backend.
- Источники цены (`storefront`, `wiki_market_summary`, `index`, `listing`, `best_bid`),
  признаки кэша / stale / неполной выборки, очередь и ошибки по площадкам / вариантам.
- Ошибки расчётов из mutation cache. Режим не меняет цены, TTL и расчёт ROI,
  не загружает серверные журналы и не создаёт дополнительных API-маршрутов.

Заголовки, тела запросов, окружение и произвольные поля ответов не показываются.
Из текстов ошибок удаляются токены, пароли и параметры URL. Журнал хранится только
в памяти вкладки и очищается при перезагрузке; новые запросы после очистки появляются снова.
Наличие ошибки в ответе HTTP 200 показывается отдельно от HTTP-результата запроса.

Проверки: 63 frontend-теста, `npm run build` и отдельный build с
`NODE_ENV=development --mode development` без debug-кода. Браузерный
`scripts/qa/check-debug.py` проверяет источники, timestamps, HTTP 503 и ошибку внутри
ответа 200, редактирование секретов, RU на 390 px и отсутствие `/debug` в preview.

Ветка не должна сливаться в `main`. Дополнительно флаг `__TRUE_ROI_DIAGNOSTICS__`
в `vite.config.ts` разрешён только для dev-сервера и исключает
маршрут, кнопку, компонент и журнал из **любой production-сборки этой ветки**, включая
`vite build --mode development` и `NODE_ENV=development`. `npm run build` проверяет отсутствие диагностики
в `dist`; `npm run preview` не включает Debug. Параметры URL и localStorage не могут
включить отсутствующий production-код. Backend и Docker production не изменены.
