# DMarket

Интеграция использует официальный Trading API: `https://api.dmarket.com`,
описание — <https://docs.dmarket.com/v1/swagger.html>. Идентификатор CS2 в API —
`a8db`. Проверено 12 ноября 2026 года.

## Что работает без ключей

`POST /marketplace-api/v1/aggregated-prices` отвечает без подписи. Один запрос
принимает до 100 точных названий и возвращает для каждого:

- `offerBestPrice` и `offerCount` — минимальная цена продажи и число предложений;
- `orderBestPrice` и `orderCount` — лучшая заявка на покупку и число заявок.

Суммы приходят в центах USD. Этого достаточно для карточек качества, сравнения
площадок, калькулятора и режима Quick flip. Для одного скина делается один
запрос на все его варианты. Лучшие заявки из того же ответа запоминаются в
памяти процесса на время TTL, поэтому Quick flip не делает лишних обращений.

В документации все методы помечены как требующие подписи. Если DMarket закроет
публичный доступ к агрегату, индекс цен продолжит работать при настроенных ключах.

## Что требует ключей

| Данные | Метод |
| --- | --- |
| Конкретные лоты (float, seed, наклейки, charms) | `GET /marketplace-api/v2/offers` |
| Список заявок на покупку (targets) | `GET /marketplace-api/v1/targets-by-title/{game_id}/{title}` |
| История продаж | `GET /trade-aggregator/v1/last-sales` |

Ключи создаются в настройках аккаунта DMarket (Trading API) и задаются в `.env`:

```dotenv
DMARKET_PUBLIC_KEY=
DMARKET_SECRET_KEY=
DMARKET_CACHE_TTL_SECONDS=300
```

Без ключей окно лотов DMarket показывает ошибку источника, вкладка истории —
недоступность продаж, а быстрая продажа — только лучшую заявку из агрегата.
Секретный ключ используется только для подписи и не попадает в ответы API и логи.

**Подписанные методы проверены модульными тестами по схеме из документации, но
не на реальном аккаунте: ключей для проверки не было.** После добавления ключей
откройте аналитику любого варианта на DMarket и убедитесь, что лоты, заявки и
продажи загрузились.

## Подпись запроса

Заголовки: `X-Api-Key` (публичный ключ, hex в нижнем регистре), `X-Sign-Date`
(unix-время в секундах, действует две минуты) и
`X-Request-Sign: dmar ed25519 <hex-подпись>`.

Подписывается строка `метод + путь + ?query + тело + время`. Параметры пути
берутся в декодированном виде (`AK-47 | Redline (Field-Tested)`), параметры
запроса — в том виде, в каком отправлены. Секретный ключ DMarket — 64 байта в hex;
первые 32 байта являются seed Ed25519. Подпись выполняет пакет `cryptography`.

## Особенности данных

- `title` в `/offers` — фильтр по префиксу, поэтому адаптер оставляет только лоты
  с точным названием и пропускает заблокированные (`locked`).
- Фильтры float, наклеек и charms применяются локально к первой странице
  (100 самых дешёвых лотов). Запрашиваются и лоты ботов DMarket, и P2P.
- История продаж отдаётся страницами по 20 записей; загружается до 100 последних.
  Цена продажи приходит строкой в долларах, а не в центах.
- Заявки с условиями по float, фазе или paint seed подходят не каждому предмету.
  В таблице они показаны, но лучшей ценой быстрой продажи считается только
  заявка без условий.
- Без ключей Quick flip берёт лучшую заявку из агрегата. Она может оказаться
  заявкой с условиями, поэтому перед сделкой цену стоит проверить на площадке.
- Ссылка на площадку ведёт на поиск по названию. Формат прямой ссылки на
  конкретный лот в документации не описан.

## Комиссии

Значения в `backend/app/marketplaces_fees.py` взяты из раздела «DMarket Fees»
на <https://dmarket.com/faq>: покупатель комиссию площадке не платит, продажа
предмета CS2 стоит 2%.

Ограничения модели:

- Для неликвидных и дешёвых предметов DMarket берёт до 10%, для части
  предметов — 1%. В расчёте используется общая ставка 2%. Точную ставку по
  названию отдаёт `GET /exchange/v1/customized-fees` (нужны ключи); этот метод
  пока не подключён, поэтому прибыль по неликвидным предметам может быть завышена.
- Комиссии пополнения и вывода в FAQ не опубликованы. Для «крипто» стоит 0%.
  Для «карты» (пополнение 0%, вывод 2,5%) использованы данные Pricempire от
  13 ноября 2026 — **площадкой не подтверждены**. Там же указана продажа 7%,
  что противоречит FAQ, поэтому в расчёте остаётся 2%.

## Лимиты

По FAQ DMarket: без авторизации — 2 запроса в секунду на лоты и 6 на остальные
методы (по IP); с ключами — 10 на лоты, 6 на историю продаж, 20 на остальные.
Индекс цен кэшируется в PostgreSQL (`marketplace_listings`, площадка `DMarket`)
на `DMARKET_CACHE_TTL_SECONDS`. Подробности варианта запрашиваются при открытии
аналитики и не кэшируются.

## API приложения

```text
GET /api/skins/{skin_id}/market/dmarket
GET /api/skins/{skin_id}/market/dmarket/listings
GET /api/variants/{variant_id}/market/dmarket
```

Площадка зарегистрирована в общем реестре, поэтому интерфейс получает её через
`/api/marketplaces` без отдельного кода.
