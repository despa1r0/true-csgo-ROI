# Tradeit.gg

У Tradeit.gg нет опубликованного API для разработчиков. Интеграция читает тот же
открытый JSON, который запрашивает витрина сайта:
`https://tradeit.gg/api/v2/inventory/data`. Авторизация и ключи не нужны.
Проверено 12 ноября 2026 года.

**Это недокументированный источник.** Tradeit.gg может изменить или закрыть его
без предупреждения. Адаптер проверяет каждое поле; при изменении формата
площадка показывает ошибку источника, а не неверную цену.

## Запросы

| Запрос | Что возвращает |
| --- | --- |
| `?gameId=730&searchValue=<текст>` | по одной строке на название предмета: цена магазина, `groupId`; в `counts` — число предметов в группе |
| `?gameId=730&groupId=<id>` | отдельные предметы группы: `assetId`, float, pattern, наклейки |

На один скин уходит один поисковый запрос: поиск по базовому названию
(`AK-47 | Redline`) возвращает все степени износа и StatTrak-варианты.
Цены кэшируются в PostgreSQL (`marketplace_listings`, площадка `Tradeit.gg`) на
`TRADEIT_CACHE_TTL_SECONDS` (по умолчанию 600 секунд).

## Какая цена используется

`storePrice` — цена покупки за деньги в центах USD. Сверено с витриной: для
`AK-47 | Redline (Field-Tested)` API вернул `2485`, сайт показал `$24.85`.

`price` и `sitePrice` — завышенная стоимость для обмена предмет-на-предмет.
В расчётах она не используется.

## Только покупка

Tradeit.gg подключён как площадка для покупки. Цена, которую сайт платит за
предмет пользователя, зависит от его инвентаря и этим запросом не отдаётся.
Поэтому:

- Tradeit.gg не предлагается как площадка продажи ни в настройках ROI, ни в
  сравнении, ни в калькуляторе; `POST /api/calculate` отвечает 422;
- истории продаж и заявок на покупку нет, ликвидность не оценивается;
- в Quick flip площадка участвует только как источник покупки.

## Ограничения

- Сопоставление идёт по точному `market_hash_name`. Doppler и Gamma Doppler на
  Tradeit.gg названы с фазой (`★ Karambit | Gamma Doppler Phase 3 (Factory New)`),
  поэтому для них цены нет.
- По части предметов поиск ничего не находит (например, отдельные наклейки).
  Такие варианты остаются без цены.
- Фильтры float, цены и наклеек применяются локально к первым 100 предметам
  группы. Данных о charms нет.
- Изображения наклеек не показываются: сайт отдаёт относительные пути без
  указанного хоста. Названия наклеек есть.
- Комиссии платёжных систем не опубликованы. Настроен способ «крипто» без
  комиссии площадки; «карта» отключена.
- Ссылка на площадку ведёт на поиск в магазине по названию.
